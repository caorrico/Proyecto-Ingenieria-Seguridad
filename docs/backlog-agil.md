- Definir alcance, roles y metodologia agil.
- Crear repositorio, estructura base y tablero de tareas.
- Documentar arquitectura inicial.

- Configurar entorno virtualizado.
- Preparar Ubuntu Server, Ubuntu Desktop, Kali Linux y Metasploitable 2.

- Implementar frontend, backend y base CRUD inicial.

## Semana 7

- Ejecutar pruebas, validacion, escaneos y analisis estadistico.
- Documentar vulnerabilidades y mitigaciones.

## Semana 8

- Redactar articulo tecnico.
- Preparar video demostrativo, presentacion y defensa final.
