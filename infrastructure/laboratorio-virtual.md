# Laboratorio virtualizado

## Maquinas

| Maquina | Funcion |
| --- | --- |
| Ubuntu Server | Backend, base de datos y API criptografica. |
| Ubuntu Desktop | Cliente legitimo de la plataforma. |
| Kali Linux | Pruebas de seguridad, escaneo y validacion de vulnerabilidades. |
| Metasploitable 2 | Sistema vulnerable para practicas controladas. |

## Recomendaciones

- Usar una red interna o NAT controlada.
- Documentar direcciones IP asignadas.
- No exponer servicios vulnerables fuera del laboratorio.
- Guardar evidencias de pruebas en `reports/`.
- Ejecutar escaneos solamente dentro del entorno autorizado.
